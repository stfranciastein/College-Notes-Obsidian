### Notes

***Render Zero Downtime Deploys.*** Render is capable of doing zero downtime deploys. If your code fails to build, it will error but continue to run your previous version. On a success, it will spin it on a different server until it can redirect it safely to the new version.

>> if your app's process doesn't exit within its specified shutdown delay (default 30 seconds), Render sends a SIGKILL signal to force the process to terminate.
