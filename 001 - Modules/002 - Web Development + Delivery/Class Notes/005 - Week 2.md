1. **Block Storage.** Amazon EBS.
2. **Object Storage.** Amazon S3.
3. **File Storage.** Amazon EFS, FSx.

***Amazon Simple Storage Service (S3).*** Stores objects in buckets. An object is a file together with a key that names it and some metadata. Total storage is **unlimited** and a single object can be 5 up to TB in size.

***Block Storage vs Object Storage.*** Block storage can change part of a file in place. Object storage replaces the whole object.
