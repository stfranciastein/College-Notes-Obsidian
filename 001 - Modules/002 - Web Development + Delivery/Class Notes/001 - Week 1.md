### DevOps (Development Operations)

Encompasses a set of practices for how web apps are delivered. There's no single 'DevOps' technology, it describes the process entirely. The three factors that make up the DevOps movement are the following:

1. **Cloud.***
2. **Automation.**
3. **Cross-Functional Teams.**

***DORA (DevOps Research and Assessment) Metrics.*** These allow you to measure the effectiveness of your deployments.

| Metric               | What it measures                                                   |
| -------------------- | ------------------------------------------------------------------ |
| Deployment frequency | How often you deploy to production                                 |
| Lead time for change | How long a change takes to go from committed to deployed           |
| Change failure rate  | How often deployments cause failures needing immediate remediation |
| Recovery time        | How long it takes to recover from a failed deployment              |

***Terraform.*** Infrastructure as code. Instead of ad-hoc spinning up servers, you define it in code. Somewhat similar to BICEP?

***JavaScript Modules in Node.js.*** CommonJS is Node's original system. **ES Modules (ESM)** were standardised into JS in 2015 (import and export). Browsers understand this natively.
