### Containerise Your App

Follow the instructions at: [Containerise Your App | Web Development and Delivery](https://webdevdelivery.com/tutorials/10-containerise-your-app/)

Remember that when you're importing to a new machine, you'll have to reinstall all of the packages in both the backend and the frontend.

When you're done, make the `Dockerfile`.

```
FROM node:22-slim

WORKDIR /app
COPY backend/package.json backend/package-lock.json ./
RUN npm ci
COPY backend/ ./

ENV PORT=8000
EXPOSE 8000
CMD ["npm", "run", "dev"]
```

Then make the `.dockerignore`

```
**/node_modules
**/dist
**/uploads
**/.env
.git
```

Continue onwards from Part: 3, Build the image. 

Note that by the end of this class I only made it to part 6. There are some 'bugs' that I ran into some problems, probably because I was missing some things from the previous class.

For part 6, you need to replace your `Dockerfile` with the following:

```
services:

  app:

    build: .

    ports:

      - "8000:8000"

    volumes:

      - ./backend:/app

      - /app/node_modules

      - uploads-data:/app/uploads

    environment:

      DB_HOST: db

      DB_PORT: 3306

      DB_USER: root

      DB_PASSWORD: notes

      DB_NAME: notes

    depends_on:

      db:

        condition: service_healthy

  

  db:

    image: mysql:8

    environment:

      MYSQL_ROOT_PASSWORD: notes

      MYSQL_DATABASE: notes

    healthcheck:

      test: ["CMD", "mysqladmin", "ping", "-h", "127.0.0.1", "-pnotes"]

      interval: 5s

      timeout: 5s

      retries: 10

    volumes:

    - db-data:/var/lib/mysql

  

volumes:

  uploads-data:

  db-data:
```

From the tutorial:

> The `volumes:` block at the bottom declares them. `db-data:/var/lib/mysql` mounts one at the path MySQL writes to, and `uploads-data:/app/uploads` does the same for the folder `uploads.js` writes attachments to.
> 
> These are **named volumes**, and they are the same mechanism as the anonymous volume in Part 4, just with a name so you can refer to them again. The `uploads-data` line sits underneath `./backend:/app` and wins for that one folder, in exactly the same way.
