### Containers

This is working off of the containers branch of Michael's repository. Run:

```
git stash
git checkout containers
```

In `Dockferfile` you need to add multi-stage 'tags' so that Docker only builds things depending on the container being built. You use the `AS` in order to specify the container. Below is what your `Dockerfile` should look like.

#### Base

```
FROM node:22-slim AS base
  

WORKDIR /app
 

# Copy the package files and install dependencies

COPY backend/package.json backend/package-lock.json ./

ENV PORT=8000

EXPOSE 8000
```

#### Development (Dev)

```
FROM base as dev

  

RUN npm ci

  

# Create uploads directory

RUN mkdir -p /app/uploads

  

# Source code is volume-mounted in development, so no COPY for src/

# This keeps the image lean and lets bind mounts handle live code

  

CMD ["npm", "run", "dev"]
```

#### Production

```
FROM base as production

ENV NODE_ENV=production

### Ignores any 'dev' dependencies

ENV npm ci --omit=dev

COPY backend/ ./

USER node

CMD ["node", "server.js"]
```

### Configurations and Secrets

***Configurations.*** A value that changes between environments but isn't sensitive.

***Secrets.*** A value that does not change per environment and is highly sensitive such as API keys.

On AWS, there is a service called Secret Service Manager (SSM) where you can configure how to manage your secrets.
