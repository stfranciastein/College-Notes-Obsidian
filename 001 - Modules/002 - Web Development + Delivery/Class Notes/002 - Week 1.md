- The default directories for everything on the college PCs seems to be Sideshow bob.

For step 2 of the tutorial, there will be a ***[CORS (Cross-Origin Resource Sharing)](https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/CORS)*** error in the terminal of the frontend. There are two ways to solve a CORS same-origin problem;
1. Have the backend send the header (saying the frontend is allowed).
2. Stop having two origins by using a proxy (server sends requests on healf of another). In this case, the solution is to edit vite.config.js).

```
import { defineConfig } from "vite";

import react from "@vitejs/plugin-react";

  

export default defineConfig({

  plugins: [react()],

  server: {

    // A proxy to forward API requests to the backend server. You can either do this or configure the frontend to directly call the backend URL.

    proxy: {

      "/api": "http://localhost:8000",

    },

  },

});
```

### Notaria

***Infrastructure as a Service (IaaS).*** low-level control over servers, disks, networks, etc. Examples include AWS and Microsoft Azure. 

***Platform as a Service (Paas).*** higher-level services. Builds code and runs it but has a low level of control/customisability. i.e. Netlify.

***Cache Busting.*** When you run NPM run build, it creates a dist folder. Inside is an index that has a hashed suffix. JS and CSS files are named with a hash, calculated from the contents of the file and ensures each 'version' is unique.
