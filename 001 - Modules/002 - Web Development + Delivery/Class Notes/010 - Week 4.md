### Continuous Integration and Delivery (CI/CD)

Almost every software company uses trunk-based development incl. Google, Amazon, Meta, etc. The idea behind trunk-based development is you make small changes to the 'main' branch which is continuously integrated and delivered in bits.

A build should be self linted and tested. Automated testing can save you trouble down the line as it reduces the amount of time it takes to QA a build which would otherwise be done manually.

____
### GitHub Actions

An event, such as a push or pull request starts a workflow. The workflow comes from a YAML file that you supply GitHub. It contains jobs i.e. a list of instructions and runners.
