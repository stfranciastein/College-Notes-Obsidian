The response will give back `np.float64(X,Y)` where X and Y is the probability rounded up to 2 decimal points. With the given data set, this will likely be 0.35-0.45.

Next, you will need to make a real-time prediction for a user who clicks link on the site and their likelihood that they'll buy. To do this, you must first define the test scenarios. There are four total test scenarios with this given dataset:
1. No pages visited
2. Only reviews (was visited)
3. Reviews, Compare Similar
4. All pages visited.

```
scenarios = {
    'No pages visited':[[0,0,0,0]],
    'Only Reviews':[[1,0,0,0]],
    'Reviews, Compare Similar':[[1,1,0,0]],
    'All pages visited':[[1,1,1,1]]
}
```

The 1s and 0s correspond to the values in the predictors table. You then need to make an empty array and populate it with a for loop before storing the scenario and results as a dictionary row.

```
# 2. Create an empty set to gather rows
results_data = []

for description, features in scenarios.items():
    proba_val = classifier.predict_proba(features)[0,1]
    percentage = round(proba_val * 100)

# 3. Store Scenario and Results as a dictionary row
    results_data.append({
        "Customer Scenario": description,
        "Propensity to Buy": f"{percentage}%"
    })

df = pd.DataFrame(results_data)
df
```
