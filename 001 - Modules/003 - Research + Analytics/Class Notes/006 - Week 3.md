To construct an algorithm that can learn and make predictions for buying, you need to use a ratio of 70:30 where 70 is the data to train the model and 30 is the testing.

```
pred_train, pred_test, tar_train, tar_test = train_test_split(predictors, targets, test_size = .3)
print('Predictor data for Training: ', pred_train.shape, 'Predictor data for Testing: ', pred_test.shape)
```

```
#1. Initialise the Random Forest Classifier model
classifier = RandomForestClassifier(n_estimators = 100, random_state = 42)
#2. Fit using our existing training arrays
classifier.fit(pred_train.values, tar_train.values)
#3. Make predictions
predictions = classifier.predict(pred_test.values)
#4. Evaluate the accuracy of the model and performance
print('Accuracy: ', accuracy_score(tar_test, predictions))
print('Confusion Matrix:\n', confusion_matrix(tar_test, predictions))
```
