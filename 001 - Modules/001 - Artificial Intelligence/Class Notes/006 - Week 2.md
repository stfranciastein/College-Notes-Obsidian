### IDE Setup & Intro to Python

The repository for this class: [IADT/y4-artificial-intelligence-26-27-y4-artificial-intelligence-stfranciastein](https://github.com/IADT/y4-artificial-intelligence-26-27-y4-artificial-intelligence-stfranciastein)

In order to integrate MCP from Mohammed's site, add this to vscode > mcp.json. This will allow co-pilot to look at Moe's notes for this module.

```
{

    "servers": {

        "docs-langchain": {

            "url": "https://docs.langchain.com/mcp"

        },

        "reference-langchain": {

            "url": "https://reference.langchain.com/mcp"

        },

        "ai": {

            "url": "https://mohammedche.ie/api/mcp/ai"

        }

    }

}

```

After working through the contents of  [[00_Setup]], you will need to run `..\.venv\Scripts\Activate.ps1` in order to enter the virtual environment.
