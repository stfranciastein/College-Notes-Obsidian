### Machine Learning (ML). 

Trains AI on patterns of data instead of explicitly programming it. For example, you can provide an ML model with many labelled examples of cats in order for it to recognise images of cats.

***K-Nearest Neighbour.*** An algorithm that is a supervised learning model that uses proximity to make predictions about the classification of a data point, K refers to the number of neighbours that are considered in making a prediction. In order to train the model properly, you need to provide it with the correct answer so that it can test itself against it. 

____
### Deep Learning (DL)

Uses multi-layered neutral networks (inspired by the brain) to automatically learn complex representations of data. 'Deep' refers to the many layers of artificial neurons. They learn from unstructured data by extracting specific features.

***Artificial Narrow Intelligence (ANI)***. AI systems that are highly specialised for specific tasks like translate language, recognise faces, etc.

***Artificial General Intelligence (AGI).*** Hypothetical 'strong' AI with human-level cognitive abilities across multiple tasks. In theory it could apply intelligence like a human. i.e. ASTRA

____
### LLMs

A language model that is trained on large corpus of text using self-supervised learning. "Large" refers to the huge amount of training data (i.e. the internet) and the model size. They predict the next word in a sequence which lets them generate human-like responses via text. 

LLMs develop their knowledge base about language and facts from their training data. It is the prime example for generative models i.e. GPT.

These can be fined tuned for specific tasks or be prompted directly.
