### CA1 - Research Paper Analyser Example

The following n8n workflow represents the example job for the CA.

![[011 - Week 4-1791805127838.webp]]

In step 2, the `edit fields` step contains the following JSON.

```
{
  "researcher": {
    "name": "Alex Morgan",
    "research_interests": ["Large Language Models", "AI Agents", "Natural Language Processing", "AI in Education"],
    "technical_knowledge": ["Python", "Machine Learning", "Transformers", "Natural Language Processing"]
  },
  "paper": {
    "title": "Agentic Systems for Educational Applications",
    "authors": ["Example Author"],
    "year": 2025,
    "abstract": "This paper investigates the use of AI agents in educational applications. The authors examine how multiple AI components can coordinate tasks such as tutoring, feedback generation and student support."
  }
}
```

In the example workflow, the model looks at the listed JSON and reasons if Alex Morgan would fine the paper interesting. All this requires is an `If` statement which checks if the `abstract` attribute of the JSON (provided in) `edit fields` exists and contains data.

`{{ $json.paper.abstract && $json.paper.abstract && String($json.paper.abstract) != ''}}`

It then prompts the OpenRouter Chat with the following message.

```
Would this researcher: {{ JSON.stringify($json.researcher) }}
find the following paper interesting: {{ JSON.stringify($json.paper) }}
```
