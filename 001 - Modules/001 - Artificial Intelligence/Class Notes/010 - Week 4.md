### Notes

***HTTP Request Methods Refresher.*** Remember that all HTTP requests expect to receive JSON and will respond with JSON. Each method outlined corresponds to CRUD respectively.

1. GET: retrieves data from a resource.
2. POST: requires the entire entity's attributes to be submitted.
3. PUT: only requires the attributes you need to replace a target resource with.
4. DELETE:: deletes a specified resource.

***OpenAI Python Client Library.*** A python utility that allows you to turn your python requests into an HTTP call. This is not a substitute for an actual LLM, it only interprets and sends your web request so that it can show you the response. The example below shows how to make a request using a Python Notebook.

```
import os
from openai import OpenAI
from dotenv import load_dotenv
load_dotenv(override=True)

api_key = os.getenv("OPENAI_API_KEY")

# Create an OpenAI python client for making web calls to OpenAI
openai = OpenAI()

# Make the call
response = openai.chat.completions.create(model="gpt-5.4-nano", messages=[{"role":"user", "content": "what is 2+2?"}])

# Print the result
print(response.choices[0].message.content)
```
