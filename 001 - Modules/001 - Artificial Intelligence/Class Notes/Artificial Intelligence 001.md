***RAG (Retrieval-Augmented Generation).*** Process of optimising the output of an LLM. This is done by providing it with the following 'steps' to follow:
1. Get external data.
2. Relevancy search.
3. Augment the LLM prompt.
4. Update the external data.

***MCP (Model Context Protocol).*** An open protocol. How an agent talks to another agent/connecting AI agents to other external tools.
