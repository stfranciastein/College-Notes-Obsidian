### Notes

***LLMs.*** Models are too large to run on the average hardware of consumer computers. They often require GPUs with high virtual memory to process.

***Quantisation.*** Losing information in order to make things such as models be 'smaller'.

***Llama.*** An LLM trained by Meta engineers and is open-source. Contains over 4b parametres. **Note that when you run a model for this course, all of it will be run locally.**

***Local AI Tech Stack.***
1. ***User Interface (UI/UX).*** Ollama comes with one.
2. ***AI Engine.*** Processes your inputs and model's outputs.
3. ***AI Model.*** Core model with trained parametres and weights.

When running a local AI, your data never leaves your device. Additionally, it's completely offline.

#### OpenWebUI

Install OpenWebUI (with Docker): 

```
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data -e WEBUI_SECRET_KEY=your-secret-key --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```
